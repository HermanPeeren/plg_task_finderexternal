Dependency Injection

A service container builds objects for you. You register how a service is made, and ask for it where you need it.

Example#

Register a service with $container->share():

$container->share(Foo::class, fn () => new Foo());
echo '<div>done</div>';
  • Shared services are built once.
  • Others are built on every request.
